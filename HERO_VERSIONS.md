# Hero Section - Две Версии

## 📋 Описание

Созданы две премиальные версии главного экрана с улучшенной визуальной глубиной и объемом:

### Version A - Photo Background (Фото-фон)
- Фоновое изображение премиального фасада/вывески справа
- Приглушенное, полупрозрачное с легким blur (opacity: 20%, blur: 2px)
- Градиентная маска для плавного растворения к центру
- Радиальное свечение (glow) за правой карточкой доверия
- Сохранена полная читаемость текста

### Version B - Abstract Legal-Tech (Абстрактный фон)
- Многослойные legal-tech элементы: shield, документы, печати
- Геометрические контуры с градиентами navy → gold
- Очень деликатная непрозрачность (opacity: 0.01-0.03)
- Множественные радиальные свечения для глубины
- Соединяющие линии между элементами

## 🎨 Общие улучшения (в обеих версиях)

1. **Фоновая сетка** - уменьшена до opacity: 0.015 (более деликатная)
2. **Радиальные свечения** - navy и gold с большим blur для мягкой глубины
3. **Декоративные элементы** - shield и document контуры с opacity 0.02
4. **Градиентные маски** - плавное растворение фона к центру
5. **Backdrop blur** - для карточки с benefits
6. **Улучшенные тени** - у trust card для объема

## 🔄 Как переключить версию

В файле `/src/app/App.tsx`:

```tsx
// Version A (Photo) - По умолчанию
<HeroVersionA />
// <HeroVersionB />

// Version B (Abstract) - Раскомментируйте эту строку и закомментируйте Version A
// <HeroVersionA />
<HeroVersionB />
```

- Заголовки, подзаголовки, CTA кнопки
